# Draw.io Code Block

Adiciona ao editor do **Draw.io Integration** um bloco de código com seleção de linguagem, realce de sintaxe, tema e números de linha.

- **Inserir:** Extras → Bloco de código..., ou botão direito no canvas → Inserir bloco de código...
- **Editar:** duplo clique no bloco
- **Aplicar:** Ctrl/Cmd+Enter

As cores ficam gravadas no diagrama, então o arquivo abre colorido em qualquer draw.io, mesmo sem esta extensão.
